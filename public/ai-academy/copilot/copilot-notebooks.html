Copilot Notebooks · curated context

Reason over selected sources

A Copilot Notebook is a persistent workspace built around the references you choose. Copilot answers from that collection instead of searching your wider work by default.

Notebooks require eligible Copilot access plus SharePoint or OneDrive; source limits vary by license.
A visible boundary for Copilot's context
📚Create a NotebookGive one project or decision its own workspace.
➕Add referencesSelect the files, Pages and material that should matter.
💬Ask within the boundaryCopilot answers from the Notebook's chosen context.
🔄Keep it currentAdd new approved sources and remove superseded ones.

Reference limits affect the design

5️⃣0️⃣

Copilot Chat notebooks

Copilot Chat users can currently add up to 50 references, and all 50 are used for grounding. Use the limit to keep the source set intentional.

3️⃣0️⃣0️⃣

Paid Copilot notebooks

Paid Microsoft Copilot users can add more than 300 references, but only up to 300 are used for grounding. A specific critical file should be added directly.

A shared location is not one reference

When you add a SharePoint site, library or folder, Copilot can consider supported files you can access in that location. It still selects a limited number of relevant files for a prompt.

📌

Add critical files directly

If one document must be considered, add that file rather than assuming it will always be selected from a large folder.

🔄

References can stay current

A linked file can reflect later changes, which is useful for ongoing work but means the Notebook's answer may change over time.

🧹

Large does not mean complete

A very large source set can still omit the one missing decision or include obsolete material. Review the boundary as the project changes.

Know the current limitations

📊

No direct visual generation

Notebooks are designed for source-grounded reasoning, not for creating charts, graphs or images directly inside the workspace.

🗑️

Deletion may be permanent

Microsoft currently documents permanent deletion for Notebooks while recovery features are still evolving. Treat deletion carefully.

🔐

Permissions still apply

The Notebook does not bypass access controls, and its answer can still be incomplete or wrong when the selected evidence is incomplete or outdated.
