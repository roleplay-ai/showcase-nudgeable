Gemini Notebook · source-grounded research

Research from your own sources

A Notebook gives Gemini and NotebookLM a selected knowledge base for one project. Use it to ask grounded questions, trace answers back to sources and keep the same evidence available as the work continues.

Notebooks sync between Gemini and NotebookLM, but the two apps use the sources differently.
Sources are the foundation of every answer
📚Add trusted sourcesUse reports, PDFs, web pages, Drive files, presentations, audio, video and other supported material.
☑️Select what should countChoose the sources that should answer the current question instead of using the entire collection automatically.
💬Ask a focused questionMention important source names when you want the answer narrowed to specific evidence.
🔗Open the citationsCheck the passage behind an important summary, comparison or recommendation.

Build a useful source collection

🔎

Find sources with Fast Research

Search the web or the Drive files you can access, review the results and import only the useful sources.

🧠

Use Deep Research for a larger search

NotebookLM can run a multi-site investigation, show the report and source list, and let you choose what to import.

🔄

Keep Drive sources current

Supported Drive sources can sync when the original file changes, so the notebook is not trapped on an old copy.

Ask questions that can be checked

Using only the selected policy documents, compare the eligibility rules for employees in India and Singapore. Cite the relevant passage for every difference and flag any point the sources do not answer.

A grounded answer is more useful when the question defines the source boundary and asks Gemini to identify missing evidence.

Keep the evidence clean

✅

Prefer current, authoritative sources

A focused collection of reliable material gives clearer answers than a large folder of drafts and duplicates.

🗂️

Remove or label outdated versions

If two files conflict, identify which one is current instead of leaving Gemini to guess.

🎯

Keep one coherent scope

Create a new Notebook when the sources and instructions no longer belong to the same project.

💡
Practical rule

Use NotebookLM when answers must stay inside selected sources. Use the same Notebook in Gemini when you also want web search and other Gemini tools.

Create Studio outputs in NotebookLM

🛠️

Open the Studio panel

Choose the output type, add any available audience, format, length or focus instructions, and start generation.

⏳

Continue working while it generates

Larger outputs such as a slide deck or video can take several minutes and are created in the background.

✏️

Review before sharing

AI-generated visuals, narration, questions and slides can contain factual or visual errors even when based on your sources.
