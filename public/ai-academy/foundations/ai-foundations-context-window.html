Context Window

The context window is the information the model can use for the current turn.

Messages, files, instructions, retrieved material and tool results can all occupy this working space.

Key insight: context is the model's current working information. Memory is a mechanism for deciding what should persist and be brought back later.

What is in the window?

Capacity is a hard limit, not a universal quality gauge

Move the slider. The useful question is how much room remains and what the product will do if the selected context exceeds capacity.

Fresh chat can remove irrelevant history

Start a new conversation when the task changes, then carry forward the brief, decisions and sources that still matter.

Memory can reintroduce selected information

Memory or retrieval can place relevant past information back into a future context window.
