Skills

Install, share and govern Skills carefully

Skills can be selected automatically, combined with other Skills and shared across a workspace. That power makes clear scope, source review and administrative controls important.

Automatic useInstallationGovernance

How ChatGPT uses a Skill

🎯

It responds to relevance

Once installed, a Skill can be used when ChatGPT decides that its method matches your request. You do not always need to remember and invoke the Skill by name.

🧩

Skills can work together

ChatGPT can use more than one installed Skill in the same request when several methods are relevant. Each Skill should therefore have a clear trigger and a focused responsibility.

📦

The package can contain more than text

A Skill may include step-by-step instructions, examples, supporting resources and executable code. More structured Skills can preserve the same sequence across repeated work.

Sharing and workspace controls

👥

Share one common process

Eligible workspace users can share a Skill with selected people or groups, or publish it to a workspace library so a team can use the same approved method.

🛡️

Administrators can set boundaries

Workspace administrators can control who may create, upload, install, share, publish or use Skills. These controls matter when Skills contain code or access business workflows.

🔍
Keep each Skill focused

If two workflows have different triggers or different definitions of good output, separate them. Focused Skills are easier for people to understand and easier for ChatGPT to select correctly.

Review Skills as reusable operational assets

A Skill can influence repeated work across many requests, so errors or unsafe code can also repeat at scale.

🧪

Test realistic inputs

Use examples that represent normal, difficult and incomplete requests. Confirm that the Skill activates at the right time and produces the expected structure without hiding uncertainty.

🔍

Inspect external packages

OpenAI may scan uploaded Skills, but that scan does not replace your own review. Examine instructions, bundled resources and code before trusting an external Skill.

🗂️

Maintain versions deliberately

When the process changes, update the Skill rather than correcting every result manually. Communicate material changes to people who rely on the shared workflow.
