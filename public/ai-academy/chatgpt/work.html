Start with a definition of done

Review these customer interviews, identify the five recurring issues, create a 10-slide leadership deck, and include supporting quotes in an appendix. Keep the existing brand and slide order.

Describe the deliverable precisely

Work performs better when it knows the output format, audience, review standard and anything that must remain unchanged.

📊

For spreadsheets

Name the sheets, columns, formulas and charts that matter. Say which formulas must be preserved and how the finished workbook should be checked.

🖥️

For presentations

Describe the audience, sections, slide types and supporting evidence. If a reference presentation is supplied, state whether its structure, brand, layout or slide order must stay intact.

📄

For documents and reports

Explain the decision the document should support, the required sections, the tone and the source material it must use. Ask for a final review against those criteria.

Frame agentic work safely

🛂

Expect pauses

Work may ask for clarification, permission or confirmation before an important action.

🔌

Prefer direct app access

Use a connected app when it can complete the action; browser interaction is a fallback for public web pages.

👀

Review before impact

Check irreversible, financial, legal or business actions before approving them.

🧭
Delegation still needs direction

Give Work the outcome, material, boundaries and review criteria. Then check the result rather than assuming every intermediate decision was right.

What Work can do with files and connected services

The best route depends on whether the material is uploaded, connected through an App or stored locally on your computer.

📚

References and templates are different

A reference file guides one task. A reusable template combines an example with standing instructions so the same type of output can be produced repeatedly.

🔌

Connected Apps are direct routes

Where supported, Work can search or act through connected services and may create native Google Docs, Sheets or Slides. The App and workspace permissions still define what is available.

🌐

Browser access has limits

Public browser interaction is useful when no App can complete the task directly, but websites may block automated access. Cloud browser also cannot complete every sign-in or payment flow.
