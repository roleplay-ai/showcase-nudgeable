Three capabilities to distinguish

🔎

Search

Fetch relevant information from the connected service when you ask.

🔄

Sync

Index selected content in advance so it can be found more quickly later.

✍️

Write action

Create, update, send or change something in the external service, subject to approvals.

Connection does not create access

🔐

Source permissions still apply

If you cannot open a file, channel, repository or record in the original service, connecting it should not bypass that limit.

✋

Important actions need attention

Sending, deleting, purchasing, sharing or changing access has more impact than reading or preparing a private draft.

👀
Review before connecting

Check which service the App uses, what it can search, whether it syncs data and which actions it is allowed to take.

Connect an App with the right approval level

The safest permission setting depends on whether the App is only reading information or can make meaningful changes in another service.

❓

Always ask

ChatGPT requests approval before any use of the App, including reading. This provides the most visibility but creates the most interruption.

✍️

Ask for changes

Reading can happen automatically, while creating, updating or sending information requires approval. This is useful when retrieval is routine but actions carry impact.

⚠️

Important actions

Routine reading may proceed automatically, but ChatGPT asks before consequential actions such as sending, deleting, purchasing, sharing or changing access.
